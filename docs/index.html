原片与建模环视

“原片画面”直接显示最终 v14 影片提取的原始 PNG，可拖移、下载，并在原始像素允许的范围内放大。

“建模环视”来自根据原片补建的实体场景，使用原生渲染的六面影像。模型的尺寸、未拍方向和细节包含推定，可能与影片不同。

八个节点用于固定位置环视，俯仰范围为上下 85°。这不代表原始影片存在已核实的共享三维模型，也不支持自由行走。

聚焦画面后，方向键移动，＋ / − 缩放，Home 或 R 复位；双击原片也可复位。放大上限按影像像素与当前画面大小调整。
